# DocMan Documentation

DocMan is a document management application for organizing documents, books, teams, projects, review workflows, and supporting metadata.

This site is focused on project maintainers:

- release branch and tag workflow
- Render deployment
- Linode deployment
- Cloudflare routing
- Atlas data safety
- production UI selection between Vue/Vuetify and the legacy React frontend

For local development and contributor setup, start with the repository README and developer onboarding guide.
